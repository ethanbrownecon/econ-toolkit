# Other resources

The best free guides, books and official documentation for each tool, picked for students. Every link here is free to read online.

!!! tip "How to use this page"
    Each section starts with one **Start here** pick. If you only have time for one resource, use that one. Come back to the others when you need more depth.

## If you only bookmark six

<div class="grid cards" markdown>

-   :material-book-open-variant:{ .lg .middle } **R for Data Science**

    The clearest introduction to working with data in R.

    [:octicons-arrow-right-24: r4ds.hadley.nz](https://r4ds.hadley.nz/)

-   :material-language-python:{ .lg .middle } **Coding for Economists**

    Python for economics, from installation to regressions.

    [:octicons-arrow-right-24: aeturrell.github.io](https://aeturrell.github.io/coding-for-economists/)

-   :material-scale-balance:{ .lg .middle } **The Effect**

    Causal inference explained in plain English, with R, Stata and Python code.

    [:octicons-arrow-right-24: theeffectbook.net](https://theeffectbook.net/)

-   :material-sigma:{ .lg .middle } **Overleaf Learn**

    Short, practical LaTeX guides for every common task.

    [:octicons-arrow-right-24: overleaf.com/learn](https://www.overleaf.com/learn)

-   :material-git:{ .lg .middle } **Happy Git and GitHub for the useR**

    Git explained for people who analyse data. Useful even if you do not use R.

    [:octicons-arrow-right-24: happygitwithr.com](https://happygitwithr.com/)

-   :material-chart-line:{ .lg .middle } **FRED**

    Free economic data you can download or pull straight into R, Python and Stata.

    [:octicons-arrow-right-24: fred.stlouisfed.org](https://fred.stlouisfed.org/)

</div>

## Where to ask for help

| Forum | Use it for |
|---|---|
| [Stack Overflow](https://stackoverflow.com/) | Programming errors in any language |
| [Cross Validated](https://stats.stackexchange.com/) | Statistics and econometrics questions |
| [Statalist](https://www.statalist.org/) | Stata questions |
| [Posit Community](https://forum.posit.co/) | R and RStudio questions |

!!! tip "Ask a good question"
    Include the code you ran, the full error message, and a small example of your data. A question that someone can reproduce in a minute gets answered quickly.
