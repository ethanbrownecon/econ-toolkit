# Coming from another tool

Already comfortable in one tool? These pages translate what you know, line by line, into Stata, R or Python.

| If you know | Start here |
|---|---|
| Stata | [Coming from Stata](stata.md) — Stata to R and Python |
| Excel | [Coming from Excel](excel.md) — formulas, filters and pivot tables to Stata, R and Python |
| R | [Coming from R](r.md) — tidyverse and fixest to Python |

Each page is a lookup table. You do not need to read it top to bottom. Find the task you want, copy the line, and change the variable names to your own.
